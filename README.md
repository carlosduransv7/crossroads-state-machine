# crossroads-state-machine

A tiny fictional state-machine / ARG prop about choices, promises, and consequences.

Nothing in this repository is a real ritual, invocation, curse, or spiritual practice. The occult atmosphere is fictional storytelling only.

## States
- `threshold` - a choice is offered
- `agreement` - the fictional pact is accepted
- `breach` - the story detects a broken promise
- `storm` - narrative chaos is triggered
- `silence` - the scene ends

Run:
```bash
python3 main.py
```
